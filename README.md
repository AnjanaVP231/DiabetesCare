# 🩺 DiabetesCare
### Diabetes Risk Prediction Using Machine Learning and Explainable AI

DiabetesCare is a web-based diabetes risk prediction application that uses Machine Learning to estimate diabetes risk and Explainable AI (XAI) techniques to make model predictions easier to understand.

The application uses a **Random Forest classification model** and provides personalized explanations through SHAP and Counterfactual Explanations.

## 🌐 Live Demo

**Website:** https://diabetescare-cgd0.onrender.com/login

DiabetesCare is deployed using Render, with Neon PostgreSQL for cloud database storage.

*Note: The free hosting service may take a little time to respond after periods of inactivity.*

## ✨ Features

- **User Authentication** – Secure registration and login with bcrypt password hashing.
- **Diabetes Risk Prediction** – Predicts diabetes risk using a trained Random Forest pipeline.
- **Prediction Probability** – Displays the model-estimated probability of diabetes.
- **SHAP Explanations** – Explains how individual input features influence the prediction.
- **Counterfactual Explanations** – Shows how changes in input values could lead to a different model prediction.
- **Prediction History** – Stores and displays previous predictions for logged-in users.
- **Diabetes Pedigree Function Calculator** – Helps calculate the diabetes pedigree function.
- **Lifestyle Information** – Provides diabetes-related lifestyle guidance.

## 🧠 Machine Learning and Explainable AI

**Machine Learning Model**
- Random Forest Classifier

**Explainable AI Techniques**
- SHAP (SHapley Additive exPlanations)
- Counterfactual Explanations

The objective is not only to predict diabetes risk but also to provide understandable explanations of the model's decisions.

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/AnjanaVP231/DiabetesCare.git
```

### 2. Navigate to the project directory

```bash
cd DiabetesCare
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment

**Windows:**

```bash
venv\Scripts\activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Configure the application

Set a secure secret key through the environment variable before running the application.

### 7. Run the application

```bash
python app.py
```

### 8. Open in  browser

```text
http://127.0.0.1:5000/
```

## 🔍 Project Objective

Many machine learning applications provide predictions without explaining why a particular result was generated.

DiabetesCare aims to address this limitation by integrating Explainable AI techniques with a diabetes risk prediction model.

It focuses on making machine learning predictions more transparent and understandable to users.

## ⚠️ Disclaimer

DiabetesCare is an academic project developed for educational and research purposes.

The predictions are generated by a machine learning model and should not be considered medical diagnoses or a substitute for professional medical advice.
